# Prizes and Getting Help

First place wins $3,000, second place $1,500, and third place $750. There is also a $500 "Best Use of RAG" prize.

Mentors are available from 9:00 AM to midnight on Saturday and from 8:00 AM to noon on Sunday. Find them at the help desk near the main entrance or post in the #help channel.

API credits: every registered team receives free LLM API credits. Ask at the help desk for your team's credit code.

If your API key stops working, first check that it is in your .env file, then ask a mentor. Never paste your API key into a public channel or commit it to GitHub.
